# Обязательные правила оформления ежедневного отчёта

Эти правила обязательны для каждого ежедневного отчёта в каталоге `reports/`.

## Хронология

1. Название области указывается на отдельной строке.
2. Каждый населённый пункт или отдельная географическая запись указывается на отдельной строке.
3. Несколько населённых пунктов внутри одной области запрещено объединять в одну визуальную строку.
4. Между блоками разных областей обязательно оставляется одна пустая строка.
5. Для гарантированного отображения переноса строки в GitHub Markdown после названия области и после каждой строки внутри блока, кроме последней перед пустой строкой, обязательно ставятся два пробела перед переводом строки (`Markdown hard line break`).

Обязательный шаблон:

```markdown
Киевская область:  
12:30, 14:15-14:20, 17:40, 19:25 – Бровары  
14:30 – Борисполь  
19:30, 20:12 – Киев

Днепропетровская область:  
12:40 – Терновка  
15:30, 16:08 – Кривой Рог
```

Итоговый отчёт считается неправильно оформленным, если при просмотре на GitHub строки с разными населёнными пунктами визуально склеиваются.
